# Assignment 4.5 — Multi-Page College Club Website

## Theory

A multi-page college club website is a website consisting of multiple interconnected web pages that provide information about a college club. It helps students learn about the club, explore its activities, register as members, and contact the club organizers. In this assignment, I created a four-page college club website using HTML.

### 1\. Home Page (`index.html`)

The home page is the main entry point of the website. It introduces the college club and provides information about its purpose, activities, and events. It also helps visitors navigate to other pages of the website.

### 2\. About Page (`about.html`)

The about page provides detailed information about the club, including its introduction, objectives, activities, and member information. It helps students understand the club's purpose and the benefits of joining it.

### 3\. Registration Page (`registration.html`)

The registration page contains a student registration form. It allows students to enter details such as their name, email address, course, and other required information. HTML form elements are used to collect the information in an organized manner.

### 4\. Contact Page (`contact.html`)

The contact page displays the club's contact information, including its email address, location, and other relevant details. It helps students contact the club organizers for inquiries and additional information.

### 5\. Consistent Navigation

Navigation links are included on all four pages to help users move easily between the home, about, registration, and contact pages. Consistent navigation improves the usability and organization of the website.

### 6\. Information Table

An HTML table is used to present information in rows and columns. For example, an events schedule can display event names, dates, times, and venues in a clear and structured format.

### 7\. Metadata and Favicon

Metadata provides information about each web page to browsers and search engines. I added essential metadata, including UTF-8 character encoding, a viewport meta tag, page titles, and meta descriptions. A favicon was also added to identify the website in the browser tab.

### 8\. Testing Internal Links

Internal links connect the different pages of the website. I tested the navigation links to ensure that each page opens correctly and users can move between all four pages without broken links.

## Conclusion

In this assignment, I created a multi-page college club website using HTML. The website includes a home page, an about page, a student registration form, and a contact page. I also implemented consistent navigation, an information table, metadata, and a favicon. Finally, I tested the internal links to ensure proper navigation between the pages. This assignment helped me understand how to organize and connect multiple web pages to create a complete and user-friendly website.
